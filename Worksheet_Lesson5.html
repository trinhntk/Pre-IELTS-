Ghi nhớ nhanh về so sánh: Tính từ/trạng từ NGẮN (1 âm tiết, hoặc 2 âm tiết tận cùng -y/-le/-ow/-er) → adj+er / adj+est. DÀI (≥2–3 âm tiết, hầu hết trạng từ -ly) → more/most + adj. Bất quy tắc: good/well → better/best; bad/badly → worse/worst; far → farther–farthest. So sánh bằng: as + adj + as / phủ định not as + adj + as.
